# 住宅ローン シミュレーター

金利変更や一部繰上返済などの「もしも」のシナリオを試して、返済額・利息・完済時期の変化を比較できる Web アプリです。
外部ライブラリやサーバー不要の静的サイトなので、`index.html` を開くだけで動作します（ブラウザに保存されるだけで、入力データは外部に送信されません）。

## 使い方

1. `mortgage-simulator/index.html` をブラウザで開く（またはこのフォルダを静的サーバーで配信する）。
2. 「設定」タブでローンの情報を入力します。
   - 借入金額・当初金利・返済期間・返済開始年月
   - 必要に応じて「2本目のローンを追加する」（ペアローン・親子ローンなど）
   - 「金利変更イベント」「一部繰上返済イベント」を追加して、将来の「もしも」を設定
3. 「結果」タブで、返済額・利息・完済予定時期や、残高の推移グラフ、返済予定表を確認します。
4. 「繰上返済 vs 投資」タブで、同じお金を繰上返済に使う場合と積立投資に回す場合を比べられます（下記）。
5. 「このシナリオを保存」で名前を付けて保存し、「シナリオ比較」タブで複数のシナリオを重ねて比較できます。

## 繰上返済 vs 積立投資 の比較について

「一括で使えるお金」「毎月使えるお金」を、次の2通りに使った場合を比べます。

- **A. 繰上返済**: お金を繰上返済（期間短縮型）にあてる。早く完済した後は、浮いた返済額も同じ利回りで積み立てる。
- **B. 積立投資**: ローンは通常どおり返済し、お金を投資信託などで積み立てる。

どちらも毎月の出費（返済額＋このお金）は同じです。元のローンの完済予定時点ではどちらもローンが残らないので、
その時点の手元の運用資産（税引後）を比べれば公平な比較になります。表示するのは数値だけで、判断はおまかせします。

- 残りの利息（このまま返済した場合）・繰上返済で減る利息・完済が早まる期間
- 積立投資の運用益（税引後）
- **損益分岐の利回り**: この利回りを上回れば積立投資、下回れば繰上返済のほうが手元資産が多くなる
- **ペイするのに必要な運用益**: 損益分岐の利回りで運用したときの運用益
- 利回り別（0〜7%）の比較表、純資産（運用資産 − ローン残高）の推移グラフ

前提: 毎月複利（年利回りを月次換算）、税金は最後に一括売却したときに運用益へ課税（NISA は非課税）。
利回りは一定と仮定しており、実際の値動き・元本割れのリスク、住宅ローン控除、団体信用生命保険、繰上返済手数料、NISA の非課税枠の上限は考慮していません。

「サンプル数値を読み込む」ボタンで、参考にした Excel シートのベースとなる数値（とも: 2,600万円 / 0.775%、まい: 1,280万円 / 0.675%、いずれも35年、2016年1月開始）を読み込めます。

## 計算方法について（元の Excel シートとの違い）

- **金利変更イベント**: 変更した時点の「残高」と「残り回数（当初の期間から算出）」から返済額を再計算します。これは実際の銀行の金利見直し方式に近い計算です。
  元の Excel シートは金利が変わっても「当初の借入額」と「当初の期間」から再計算していたため、実際の返済とは異なる金額になっていました。
- **一部繰上返済イベント**: 次のいずれかを選べます。
  - **期間短縮型**：返済額は変えず、完済が早まる
  - **返済額低減型**：残りの期間は変えず、返済額が下がる
- 毎月の返済額は円未満を切り捨てて計算します（実際の返済慣行に合わせています）。最終回は残高に合わせて自動調整されます。
- 上記の理由により、この計算結果は元の Excel シートの数値と完全には一致しません（数千円〜数万円程度、35年間の合計でごくわずかな差になります）。より実際の返済に近い金額を優先しています。

## ファイル構成

```
mortgage-simulator/
├── index.html          画面構造
├── css/style.css        スタイル（ライト/ダークモード対応）
├── js/amortization.js   返済計算エンジン（ロジックのみ、UI 非依存）
├── js/invest.js         繰上返済 vs 積立投資の比較計算（UI 非依存）
├── js/charts.js         SVG チャート描画（残高推移・累計利息/元金）
└── js/app.js            画面の状態管理・イベント処理
```

## データの保存について

入力したローン情報・シナリオは、ブラウザの `localStorage` にのみ保存されます。外部サーバーへの送信は行いません。別のブラウザ・別の端末では共有されないため、必要であれば手動で同じ値を入力してください。
